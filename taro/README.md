# Midnight Tarot · 오늘의 타로

375px 모바일 우선으로 구현한 실행 가능한 타로 웹서비스입니다.

## 실행 방법

```bash
cd taro
npm install
npm run dev
```

Vite가 출력하는 로컬 주소를 열고 브라우저 개발자 도구에서 뷰포트를 375px로 설정하면 모바일 화면을 확인할 수 있습니다.

## 프로덕션 빌드

```bash
npm run build
npm run preview
```

## 구현 기능

- 시작 → 내 정보·주제 입력 → 결과의 3단계 흐름
- 이름(최대 10자), 생년월일 필수 / 전공 선택
- 커리어·재물·연애·건강·학업·종합 6개 주제
- 메이저 아르카나 22장 중 정방향 한 장 무작위 추첨
- 생년월일 기반 별자리와 전공 계열을 반영한 3줄 이내 해석
- 카드 뒤집기 모션, 1080×1350 PNG 저장
- Web Share API로 결과 이미지와 메시지 공유, 미지원 환경에서는 메시지 복사
- 다시 뽑기 시 입력 화면으로 돌아가 주제를 변경할 수 있고, 처음으로 시 입력값 초기화

## 개인정보 보호

이름·생년월일·전공은 브라우저 메모리에서만 처리합니다. 서버로 전송하거나 localStorage·쿠키에 저장하지 않습니다. 처음으로 돌아가거나 페이지를 닫으면 입력 정보가 초기화됩니다. 결과 이미지와 공유 메시지에는 생년월일 및 전공 원문을 포함하지 않습니다.

## 기술

- Vite 6
- HTML / CSS / Vanilla JavaScript
- CSS 변수에 Tailwind·shadcn/ui 의미 기반 토큰 네이밍 반영
- 인증·AI·분석 SDK 및 백엔드 호출 없음
