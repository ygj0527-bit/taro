# 오늘의 타로 · Midnight Tarot

가입 없이 이름·생년월일·선택 전공과 주제를 입력하고, 메이저 아르카나 22장 중 한 장으로 짧은 개인화 해석을 확인하는 모바일 웹서비스입니다.

## 실행

- [서비스 화면 소스](./taro/index.html)
- 빌드 도구나 패키지 설치 없이 `taro/index.html`을 브라우저에서 열면 실행됩니다.
- 모바일 기준 화면은 375px이며, 데스크톱에서는 모바일 폭으로 가운데 정렬됩니다.

## 화면

1. **S-01 시작** — 오늘의 타로 소개, 카드 뒷면, 시작 CTA
2. **S-02 입력** — 이름, 생년월일, 선택 전공, 주제 6종, 개인정보 안내
3. **S-03 결과** — 정방향 메이저 아르카나 1장, 별자리·전공 계열 맞춤 해석, PNG 저장·공유·복사·다시 뽑기·초기화

## 개인정보

- 입력값은 브라우저 메모리에서만 사용합니다.
- 서버 전송, localStorage/sessionStorage, 쿠키, 분석 도구를 사용하지 않습니다.
- 처음으로 돌아가거나 페이지를 닫으면 입력 상태를 비웁니다.
- 생년월일과 전공 원문은 결과 이미지 및 공유 문구에 포함하지 않습니다.
